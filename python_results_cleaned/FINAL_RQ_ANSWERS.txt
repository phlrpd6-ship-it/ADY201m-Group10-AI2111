Using Random Forest, baseline F2=0.8524 and SMOTE F2=0.8518 (delta=-0.0006). Recall changed from 0.8683 to 0.8682 (delta=-0.0002). Thresholds were optimized using validation only and SMOTE was applied only to the training set.

RQ3 ANSWER - SHAP:
SHAP successfully produced global feature importance and student/record-specific explanations. Positive SHAP values push predictions toward TARGET=1 (unsuccessful), while negative SHAP values push predictions toward TARGET=0 (successful) (as explained for the recorded explained_class). SHAP explains the selected model trained on SMOTE-resampled training data, using interventional feature perturbation with a 100-row background drawn from the original (pre-SMOTE) imputed training data. SHAP explains model behavior and does not prove causal root causes.
